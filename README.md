# Ordering system for pixl

This is a little frontend webapp that i wrote in html/css/js it was great getting back into coding again and back into javascript but next time I plan on trying something new
## Description
This is a project for https://pixl.hackclub.com/to complete a quest.
Its made in html/css/js. It uses localStorage to save the items you "bought" json handleing to hold all the info about the "produtcs"
It's basically spagetti code cuz i didnt have time to actually make it readable
